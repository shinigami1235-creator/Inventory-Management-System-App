1. Opening the app
  1. Open the app file in Chrome, Safari or Edge. It needs no install, account or internet.
  2. Everything saves to this browser as you work.
  3. Install it on a tablet: open the clinic's web address for the app in Chrome, tap the menu, then Install app or Add to Home screen. On an iPad, use Safari's Share button, then Add to Home Screen. The installed app opens from its own icon, works with no internet and updates the next time it opens with a connection.
  4. The installed app keeps its data apart from the file opened directly. To carry data over, Export All Data from the old copy and Import it into the installed app (Admin > Data / Backup).
  5. Each tablet keeps its own data. Move data between tablets with Export and Import (section 10).
2. First-time setup
  1. Open the Admin tab. The first time, it asks for an admin password for the Admin tab and your own staff PIN of 4 to 8 digits, which you enter to deduct, restock or log a service.
  2. Setup runs once on each device. It asks again only if the browser's data is cleared (see Troubleshooting).
  3. The product catalog and sample services and packages are loaded already. Change or delete them in Admin > Inventory and Admin > Services & Packages.
  4. Add your team in Admin > Staff, each with their own PIN.
  5. Add photos and set prices, stock and restock thresholds in Admin > Inventory.
  6. Admin locks again when the page reloads or the browser closes. Staff never need the admin password for daily work.
3. Deducting products
  1. On the Products tab, tap a product to add one to the list. Tap it again to add more.
  2. Tap Review & Deduct and pick the patient. A patient is required every time, since patient history is built from it. Add a promo code if there is one and choose how they paid.
  3. A promo code discounts only the products and services it was set up for in Admin > Promo Codes, once per patient per item.
  4. An Ambassador or VIP patient gets their discount automatically. When a promo code, the Ambassador discount and a VIP discount could all apply to one item, only the largest one applies.
  5. Tap Deduct from Stock and enter the staff PIN of whoever is handling it. The items are logged as purchased and taken out of stock. No receipt is issued, so write one by hand if the patient needs one.
  6. Staff must clock in on the Attendance tab before they can deduct anything.
4. QR labels and scanning
  1. Print labels: in Admin > Inventory, tap QR Label on a product, pick the branch the stock belongs to and how many labels, then tap Print Labels. Print QR Labels at the top prints a sheet for every item listed, one each or one per unit in stock. Download PNG saves a single label to send to a print shop.
  2. Print labels at least 2 cm across and stick them flat on the product.
  3. Scan: on the Products tab, tap Scan QR and allow the camera. Hold each label up to the camera. Every scan adds one item to the list and the scanner stays open for the next one. Tap Done, then Review & Deduct.
  4. A scanned item comes out of the branch printed on its label. A tapped item comes out of this tablet's own branch.
  5. If the camera will not start, tap Scan from a photo. It opens the camera app, and the code is read from the picture you take.
5. Services, packages and vouchers
  1. Log a Service is for a one-off treatment. Pick the patient, how they paid, and any voucher or promo code.
  2. Log a Package is for a prepaid bundle of sessions. Each service in the package gets its own first visit on the calendar, on its own interval. The dates are filled in for you and can be changed, or cleared to skip booking one.
  3. Redeem a Session is for a patient using a session they already paid for. Find them, tap Redeem, and pick which service it is for when the package has more than one. Redeeming books that service's next visit on its own interval until its sessions run out.
  4. Days between visits: a regular package sets one in Admin > Services & Packages. A custom package sets one per service, for example diode every 14 days and skin booster every 21 days. Left blank, the service's own Next visit setting is used.
  5. Custom packages are built for one patient in Admin > Patients > Custom Package. They show only for that patient, under "Custom package for one patient" in Log a Package.
  6. Vouchers: in Admin > Patients, tap Vouchers on a patient. Choose percent off, a peso amount off or a free service. Set it to One use in total or Once per service and tick the services it covers. Print the QR code or download it to send to the patient. A patient can hold several vouchers at once.
  7. To use a voucher, tap Scan next to Patient voucher on Log a Service, or type its code. It works only for the patient it was made for. A one-use voucher is used up after one service, and a once-per-service voucher is used up when every ticked service has had it. Used-up vouchers move to the history list under the patient's vouchers. Voiding the service frees that use again.
6. Patients
  1. Add a patient on the Patients tab.
  2. Tap a patient to see every product, service and package they had, with dates, and their Upcoming Appointments. Book a visit from there. Edit Patient changes the name, contact details, email or notes.
  3. Delete Patient works only for a patient with no purchase, service or package history, and asks for an admin PIN or a PIN allowed to void. A patient with history can be edited but never deleted.
  4. Tags are labels you make up, such as wrinkles or regular. Add or remove them on the patient's screen. Typing an existing tag reuses it in any capitalization. Tap a tag above the patient list to show everyone with it, and tap a second tag to also show patients with that one.
  5. Admin > Patients makes a patient an Ambassador and sets their discount. Manage Tags there removes a tag from every patient at once.
  6. VIP comes automatically once a patient's product purchases reach the amount in Admin > Settings (₱50,000 by default). Services do not count. The patient's screen shows their progress. The purchase that reaches the amount is charged in full and the VIP discount starts on the next visit.
  7. Admin > Patients can also grant or remove VIP by hand. Removing it resets the count to zero.
  8. Each product and service sets its own VIP discount on its Edit screen. Admin > Patients > VIP Discounts sets a different discount for one patient.
  9. Exporting one patient's report asks for the admin password again. It downloads as a .csv file that opens in Excel.
7. Marketing and appointment reminders
  1. Write a template: in Admin > Message Templates, write the reminder once. Tap a blank to insert it: {name}, {first_name}, {date}, {time}, {service} and {clinic}. The preview shows how it will read. {clinic} uses the clinic name in Admin > Settings.
  2. Send reminders: on the Calendar tab, tap a day, then Send Reminders. The Marketing tab opens with everyone booked that day and each message already filled in with their name, service, date and time. You can also pick the date at the top of Marketing.
  3. Each patient has buttons for WhatsApp, Text Message, Gmail and Facebook, depending on what is on their record. Each one opens with the message ready. Tap Send yourself. For Facebook, the app copies the message and you paste it into the chat.
  4. You can edit a message before sending it.
  5. Email further down opens Gmail with your patients' addresses in Bcc. The To field stays empty. If Bcc is empty as well, the list was too long, so pick about 50 patients at a time.
  6. WhatsApp opens one chat at a time with your message filled in. Add each patient's WhatsApp number on their record first.
  7. Facebook Messenger only lists patients with a Facebook link who agreed to be contacted that way (both set on Edit Patient). Chats open empty, so paste the message in yourself.
8. Calendar and scheduling
  1. Tap + Book Appointment to book a visit by hand: patient, service, date, time and notes.
  2. The month grid shows a count on each day with bookings. Tap a day to see its list, where each booking can be marked done, edited or deleted.
  3. Packages book each service separately. A package with diode every 14 days and skin booster every 21 days shows both on the calendar, each on its own dates.
  4. Next visit after this many days on a service books the patient's next visit for that service as soon as one is logged, counted from the day the visit happened.
  5. Logging a visit marks that patient's booking for the same service as done, even when they come in before the booked date.
  6. A booking still open after its date shows as missed with a banner. Log the visit if the patient comes in late, or delete the booking.
  7. Send Reminders on a day opens that day's reminder list in Marketing (section 7).
9. Inventory, consumables and branches
  1. The Inventory tab has Products (what patients take home) and Consumables (gloves, syringes, ml of product used during treatments). Consumables never show on the Products tab. Tick Clinic supply on an item in Admin > Inventory to make it one.
  2. Restock adds stock and Pull-out takes it off the shelf (damaged, expired, recalled). Both ask for a staff PIN.
  3. Log Usage on a consumable records waste such as a torn glove.
  4. A service or package can list the consumables it uses per session (Admin > Services & Packages). They come out of stock automatically each time it is logged.
  5. Branches: add them in Admin > Branches. Each branch keeps its own stock and the overall total is the sum. The first branch you add takes over all current stock. On each tablet, set This tablet to the branch it sits in.
  6. Pick a branch at the top of the Inventory tab to see its own counts, or All branches for the overall total with each branch listed under it. Restock, Pull-out and Log Usage ask which branch. Transfer moves stock from one branch to another.
  7. A low-stock banner appears once an item's overall stock reaches its threshold.
10. Backup and moving to a new device

The data lives only in this browser on this device. Export and Import are the only way to keep a spare copy or move to another tablet.

  1. Go to Admin > Data / Backup.
  2. Export All Data downloads one .json file with every product, staff PIN, patient, purchase, setting and photo. Keep it off the tablet, in email, cloud storage or a USB drive. Export once a week and before any big catalog change.
  3. Moving to a new device or browser: export on the old one, copy the .json file over, open the app on the new device and use Import there.
  4. Import replaces every product, staff member, patient and purchase on this device with the file's contents. It asks for this device's admin password and a typed confirmation. The admin password on this device stays the same after an import.
  5. Export a backup of the current data before importing.
  6. A file from the online (Supabase) edition cannot be imported here, or the other way round, since the two encrypt staff PINs differently.
11. Troubleshooting
  • Nothing loads or a red banner appears: the browser could not open its storage. Reload first. A private or incognito window can block storage, so use a normal window. If it keeps happening, send the detail in the banner to whoever looks after the app.
  • Setup asks again after it was done: the browser's data for this app was cleared, for example by "Clear browsing data" or a private window. Import a recent Export file to bring everything back, admin password included.
  • Two tablets show different data: each tablet keeps its own data. Move data between them with Export and Import (section 10).
  • Forgot the admin password: there is no reset button. Contact whoever built or looks after the app.
  • A stock count looks wrong: check Admin > Branches > Stock Transfers and ask the owner to check the records. Every deduction, restock, pull-out and transfer is logged with who did it and when.
  • The camera will not open for scanning: allow camera access for this page in the browser settings, or use Scan from a photo.
  • The renamed file opens empty: the browser keeps the old file's data separately. Open the old file, Export All Data, then Import that file in the new one.
